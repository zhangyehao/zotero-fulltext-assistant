# 1.1.0 更新说明

**状态：发布前候选验收完成，待公开发行与公开更新验证。** 本页记录 2026-11-15 验收的精确候选；实际发行状态以正式 Release 为准。正式更新入口可用后，还须独立核对匿名资产下载及旧版升级，不把候选检查现有更新源算作升级成功。

1.1.0 增加知网文献解析、元数据预览与明确导入、参考文献提取，并把网站提供的 PDF 接入现有全文获取流程。没有 DOI 的条目可保留知网文献标识；知网会话与来源设置集中在现有设置页中。

## 新增与改进

- **知网文献识别。** 支持明确的知网文章详情网址及数据库、文件标识；有 DOI 时结合 DOI 核对，没有 DOI 时不编造 DOI。保留学位论文等文件标识中的有效字符，已知期刊类别 `CJFQ` 与 `CJFD` 规范为同一身份，其他数据库或文件名冲突仍拒绝关联。
- **预览后导入与补全。** 文章网址先显示可取得的题名、作者等资料，由用户明确导入；导入前查重。已有条目的元数据补全只填空字段。仅有中文题名时提供官方搜索入口，需要先确认正确文章。
- **参考文献。** 读取文章页可见的直接参考文献，及该页明确声明的同站列表；保留分组、原文与可可靠识别的题录字段，区分部分结果、未知总数和访问限制。默认不勾选，每次明确导入 1–50 条；缺少可靠题名的原始引文不能直接建条目。导入的是文献资料，之后仍需单独获取全文。
- **PDF 获取与身份核对。** 使用页面实际提供的 PDF 入口，经过原有格式与论文身份核对后才保存附件。中文长题名的换行与相邻汉字间空白纳入核对，摘要或参考文献中出现目标标题不作为本文标题证据。可靠 DOI、题名或知网标识冲突继续拒绝；仅有 CAJ 不作为 PDF 成功。
- **现有设置页内管理。** 在“设置 → 知网”中提供来源开关、网页登录、访问验证与知网范围的会话重置，保留任务、消息、通用设置和科研通设置的分工。来源默认开启；网址草稿、参考文献选择和未保存输入在无关刷新或语言切换后保留。
- **三语与状态说明。** 简体中文、繁体中文、英文覆盖新入口、进度和错误。元数据可读取、允许保存会话、实际登录及下载权限分别显示，不把其中一项当作另一项已完成。

不需要安装浏览器扩展、Reference 或 Jasminum。知网功能独立实现；第三方项目仅作功能研究，没有复制其 AGPL 实现。具体操作与网站限制见 [知网说明](cnki.md)。

## 更新与兼容

候选安装包文件名为 `zotero-fulltext-assistant-1.1.0.xpi`，兼容声明保持 **Zotero 10.0.7–10.0.***；本版实际原生测试环境为 **Windows / Zotero 10.0.8**。保留既有插件 ID、公开更新地址和任务存储格式，不要求重建文库。

已有有效本地全文的跳过、批次追加、跨批次未完成、倒序完成历史、科研通积分授权与采纳凭证规则保持兼容。普通批量获取不自动发布付积分求助。原始 0.7.x 仍需手动安装一次 0.8.0 或之后的版本；已有公开更新入口的版本沿用 Zotero 原生更新链路。

## 仍需验证的访问条件

**真实机构授权的知网 PDF 下载、完整参考文献列表以及知网登录跨进程恢复尚未验证。** 本版已实现相关入口、状态与恢复机制，但公开元数据可读、合成数据测试通过或会话保存授权存在，都不证明实际机构权限可用。

知网与其他出版社使用 Zotero 网站会话，插件不读取日常 Edge / Chrome Cookie。需要人工验证时由用户在网站完成；机构权限、网站到期、购买确认、访问限制和服务降级都可能影响结果。默认浏览器能下载时，可使用既有 [下载目录检查与人工核对](browser-downloads.md) 流程。

本版不内置未获授权的知网 OpenX 应用凭据，不自动购买文献，不将 CAJ 改名为 PDF，也不承诺全部中文文献或完整参考文献均可获取。全文来源与 API 边界见 [来源说明](fulltext-sources.md)，本地数据与联网范围见 [隐私说明](../PRIVACY.md)。
