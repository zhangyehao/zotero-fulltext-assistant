# 1.1.2 更新说明

**状态：最终候选验收完成，待公开发行与旧版公开更新验证。** 本页记录 2026-11-16 验收的精确候选，正式状态以 Release 为准。

1.1.2 修复“已在知网窗口登录，但检查仍显示通用失败”的误导性行为：检查可能选中了其他网站的 DOI，旧验证缓存也可能让人工完成验证后的重试没有重新请求页面。现在界面明确检查具体文献，并保留失败原因。

## 本次改动

- **检查文献访问。** 按钮使用当前输入；为空时依次使用有效预览、选中的明确知网条目、文库中的明确知网条目。普通 DOI 不再自动当作知网样本；显式输入 DOI 仍可解析，指向其他网站时显示相应原因。
- **账号与文献状态分开。** 允许保存会话、打开登录窗口及文献访问检查都不等于验证账号登录。打开登录窗口会清掉旧检查错误和时间；没有样本时提示提供文献。
- **具体失败原因。** 区分超时、网络失败、HTTP 错误、限流、不支持的页面、跳转限制、响应过大及文献冲突；题录或编号不足显示“文献信息不足”。三语提示不再把这些结果统一解释成需要登录。
- **人工验证后可重新检查。** 主动解析或检查清除当前目标站点的旧人工验证缓存，再次请求页面；DOI 先解析到实际目标。后台批量保留门禁冷却，不自动反复重试。
- **输入与预览一致。** 无效非空输入不会改查其他条目；输入改变后，迟到结果不能允许导入上一文献的预览。文献身份冲突产生的失败预览不会用于空输入重试，避免丢失原条目的身份核验条件。

操作见 [知网说明](cnki.md)。本版保留现有插件 ID、公开更新入口、schema 1 任务格式和 Zotero **10.0.7–10.0.*** 安装范围；任务、历史、附件关联及科研通规则继续沿用。
