## 真实页面与正式文库

- 最终包在隔离配置中复用了已保存的科研通会话，真实 GET 查询确认本人账号余额、当日签到及明确签到入账；奖励来自本人积分明细，不由余额变化推算。任务数据未被该查询改变，查询状态成功保存。
- 官网当前说明禁止程序自动签到。本版没有自动签到写接口；提供本机时间每天 06:00 后及打开助手时的只读检查、官方签到入口和奖励核实。关闭 Zotero 时不运行。每日定时、跨日、并发、换号及失败节流由受控时钟测试覆盖，不宣称已经等待多个真实自然日验证。
- 当前 DOI 只读查询与用户反馈条目的 DOI 一致，未重现此前 DOI 不符。历史响应未保留，不能据此宣称查明了历史不符的根因；新版本明确区分发布前错误与已有求助待核对，并保存两侧 DOI 证据。
- 正式验证发现科研通下载页长文件名正文以省略号截短、完整名保存在 `title` 属性，导致旧比较误拒绝。最终包依据完整名与正文一致性修复，并增加错文件、矛盾正文、无完整名及重复节点反例。
- 用户反馈的已有手动导入记录，在正式界面触发“核验科研通文件”后，完成论文身份和完整文件字节核验。来源恢复为科研通，原附件及原完成时间不变，原悬赏金额已核实，网站确认采纳且对应消息已读。该操作处理既有求助，没有重建求助或重复导入附件。

正式配置中的最终安装包与上述实测 SHA-256 一致，插件启用并处于活动状态。更新前后 74 条任务全部保留，74 条已获取记录的附件关联和完成时间保持；最近批次、3 个下载目录及简体中文配置保持。

原生界面已观察到横向四标签、居中的数字输入、默认关闭的最低积分选项、默认开启的签到检查、余额及明确奖励显示、本地支出统计和完成历史倒序。最终包界面同时显示反馈记录“已采纳 · 对应消息已读”及已核实的原悬赏金额。

## 行为边界

- 支出统计汇总本机已保存、已采纳的求助，按求助编号去重；未知金额单独提示，不计入金额或均价。它不代表网站完整账单，余额另由本人账号页面读取。
- 没有当日明确签到凭据时显示待核实，不把连续签到天数、缺少按钮或打开网页当作签到成功。旧余额保留查询时间，跨日不沿用昨天的签到或奖励状态。
- 文件名校验通过仅允许继续获取文件；自动入库、恢复来源和采纳还需论文身份及内容核验。无法确认的手选应助 PDF 须预览并明确确认；明确错篇拒绝。
- 站点可能变更页面、登录或下载协议，当前实测不构成所有出版社、所有文献或永久登录的保证。真人验证由用户在正常网页中操作。
- HTML 使用说明与验收记录做结构和本地链接检查；不把这些静态检查描述为浏览器渲染验收。实际插件界面另经过原生截图核对。
