## 合成知网、中文核对与界面检查

知网原生组使用实际 Gecko DOMParser 和已安装模块，对合成文章/参考页面检查：没有 DOI 时保留知网标识；直接参考文献排除引证和二级参考文献；没有可靠题名的原始引文不能导入；期刊、会议、博士论文、硕士论文和报纸类型保持区分；没有凭空生成 DOI。这部分没有访问真实论文列表，也没有持久化合成参考条目。

中文长题名核对检查采用**注入的提取文本**：换行与相邻汉字空白的长题名可以匹配，摘要中的他文引用不能被当作本文身份。本组没有读取真实中文 PDF 文件。通用下载组另以合成 PDF 文件经过真实 PDFWorker 覆盖匹配、冲突、参考 DOI 和证据不足等情形；它仍不是机构授权知网 PDF 的实测。

原生设置检查确认知网位于现有“设置”分页，新增按钮和状态在简体中文、繁体中文、英文可显示；来源开关保存并恢复。“允许保存会话”与“登录成功/有下载权限”分别表述。知网任务关联、来源设置、语言与保存授权在测试后恢复。网址草稿、列表选择、分页、取消后的已提交数量等更多交互由 DOM/控制器回归覆盖，不把它们都称为真实网站原生导入成功。

另在实际 Zotero 设置页完成人工视觉检查：知网区块、元数据预览和参考文献卡片布局正常，未出现额外管理窗口或可见文本溢出。

## 真实开放全文验证

公开样本为 **Array programming with NumPy**，DOI `10.1038/s41586-020-2649-2`，PMCID `PMC7759461`。本轮从 Europe PMC 发现官方 PMC 数据集元数据，并下载实际 PDF，结果如下：

- 实际请求均匿名，没有读取 API key，也没有使用机构或科研通会话。
- 下载文件为 **1,218,474 字节**；PDF SHA-256 为 `6728d4ba00fcb73e7872b1cb4b05a7a51482a152da6a9464a15d8f6dcdeb8a3d`。
- Zotero 原生 PDFWorker 提取文字，目标 DOI 匹配后保存至隔离临时条目，父条目、文库及附件存储位置正确；保存后再次核对仍为 DOI 匹配。
- 临时条目与测试文件已清理，任务文件和原来源额度记录未改变。

这是一篇公开 PDF 的真实获取验证，不是所有来源的覆盖率，也没有在 1.1.0 重跑旧版的 50 篇联合来源基准。知网组的 0 次 PDF 获取与此 PMC 成功分别统计，不混为知网下载成功。
