# 专用 Edge 全文获取：开发说明

本文对应 0.4.1，记录截至 2026-11-05 的实现约定。用户只需安装 Zotero 插件，本机需已有 Microsoft Edge；无需配套 Edge 扩展。下方历史报告明确标为 0.4.0 的验证，不作为 0.4.1 的重新验收。

用户从任务中的“专用 Edge 自动获取”启动全文助手专用 Edge，首次在该窗口自行完成出版社或机构登录、真人验证。只有网站接受该专用会话，插件才继续识别当前论文并获取可下载的 PDF；成功后附件保存到原条目，任务进入“已获取”，来源显示“Edge 浏览器”。等待期间可继续使用 Zotero；用户无须额外点击“验证完成”。

## 0.4.1 验证等待与默认浏览器

候选下载触发网站验证后建立任务级等待，所有关联页面暂停文件请求。只有验证页面或后代页面连续两次稳定出现匹配的论文和 PDF 入口，或批准地址上的 PDF 文档，才恢复；提示文字变化、未知过渡页和原文页 loader 变化不算完成。会话协议错误明确结束获取，不继续轮询失效会话。

`openSystemBrowserTask(id)` 取消并等待本任务清理后调用 `Zotero.launchURL`，保留其他任务的专用 Edge。系统默认浏览器不受插件控制，用户自行保存 PDF，再通过已有文件选择器导入原条目。取消、切换、文件选择与完成历史使用原任务；不会新发科研通求助。该路径不依赖浏览器扩展，也不读取浏览器配置、Cookie 或历史。

## 会话与连接

`src/edge-host.js` 启动独立 Edge 进程，使用 Zotero 配置目录下的 `fulltext-assistant-edge` 持久资料目录和随机远程调试端口。桥接从专用目录的 `DevToolsActivePort` 读取端点，仅连接 `127.0.0.1` 回环 WebSocket，通过 Edge DevTools Protocol / CDP 收发命令。组织策略禁止远程调试、开发工具或固定资料目录时返回错误，不修改策略。资料目录不允许符号链接或目录联接。

出版社、机构网站的登录由专用 Edge 自己保存和使用。此会话与日常 Edge、Zotero 内嵌出版社窗口、科研通登录窗口相互独立；不会读取、复制或导出日常 Edge 的 Cookie，也不通过 CDP 导出专用会话 Cookie。重启后复用专用资料目录，登录是否仍有效由网站的有效期和撤销机制决定。停止插件或退出 Zotero 会关闭专用 Edge，保留资料目录。

## 页面与论文身份

`src/edge-acquire.js` 只跟踪本次任务创建的根页面，以及可由 `openerId` 追溯到它的子页面；不会扫描同一浏览器中其他无关标签页。只读页面检查提取 DOI、完整标题、候选 PDF 链接和非个人化的登录/验证状态，不返回整页正文、表单值或账号信息。

候选下载必须来自身份已核实的文章页：优先核对 DOI，无可用页面 DOI 时才采用足够明确的完整标题；页面 DOI 冲突时不下载。支持文章 PDF 元数据和明确的 HTTP(S) PDF 入口，排除识别出的参考文献、相关文献、补充材料及勘误入口。子页直接显示 PDF 时，其地址仍须来自此前已验证文章页的候选。读取前后还检查页面与导航身份；一个 HTML 中间页也必须具有自己的论文身份依据。

PDF 通过同一个 Edge 会话读取，使用该会话已有的访问权限，校验完整 PDF 后才交给 Zotero。启动或继续任务时刷新原条目的 DOI、标题和 URL；保存前复核原条目、文库权限及本次获取的 DOI，真正无 DOI 时复核标题。发现身份变化就停止导入，避免把已取得的论文保存到被修改的条目。

## 任务约定

`src/app.js` 的 `openExternalTask(id)` 启动独立后台任务并快速返回 `{started:true}`；人工验证等待不占用普通批量获取工作队列。任务保存 `acquisitionMode: "browser"`，进度由订阅通知更新。

| 情况 | 界面与后端行为 |
| --- | --- |
| `browser_waiting` / `browser_scanning` / `browser_downloading` | 显示“等待网页就绪 / 正在检测 PDF / 浏览器下载中”，详细进度说明所需人工操作；提供“查看浏览器”“暂停”和“默认浏览器手动下载”，不显示积分，不能勾选或发起科研通求助。 |
| 暂停、退出或重启后未完成 | 保留任务与专用登录资料，明确点击“继续专用 Edge 获取”恢复；恢复操作不会改走科研通积分重试。 |
| 浏览器获取失败或未找到全文 | 保留原因，可继续浏览器获取、导入已下载 PDF，或明确选择科研通兜底。显式 `requestAssist` 才清除浏览器模式并进入求助流程。 |
| 已关联科研通求助 | 使用已有求助的检查、下载与打开操作；不启动出版社 Edge 获取。关联已有求助时清除浏览器模式。 |
| 获取成功 | 记录 `source: "edge_browser"`、附件及完成时间；再次操作优先复用已有有效 PDF。 |

暂停与停止使用任务取消标记，阻止迟到的下载结果继续入库。停止流程等待浏览器任务收敛及最后一次队列保存；若附件已经进入提交过程，需保留实际完成结果，不能让旧实例在停止返回后继续覆盖队列。当前专项验证和应用层回归共同覆盖这些约定，最终安装包仍须复验生命周期。

## 支持范围与验证证据

不自动操作验证码，不伪装或绕过网站验证，不保证任一机构或出版社允许访问。当前自动获取支持页面暴露的普通 HTTP(S) PDF 链接；纯 JavaScript、`blob:` 或必须通过 POST 生成的下载不在支持范围。单个 PDF 上限 100 MiB，人工验证或等待入口最多 15 分钟；超时后显示原因并允许用户继续。文件格式校验和网页身份核对不能证明所有出版社的链接语义都可靠，应避免把单站成功扩展成全面兼容承诺。
