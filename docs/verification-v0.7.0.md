## 任务分类与批次

设置页保留 **任务 / 下载设置 / 科研通账号 / 消息** 四个横向标签。任务筛选依次为 **进行中 / 需网页登录 / 待兜底 / 已获取 / 未完成 / 全部历史**。前四类只统计最近一次持久保存的当前批次；“未完成”跨批次保留待处理及未收尾记录；“全部历史”只显示已获取任务，按完成时间从新到旧排序。旧版记录没有批次信息时不会被虚构成当前批次，仍可从未完成与历史查看；下一次批量获取建立当前批次。

当前批次保存批次标识、创建时间、任务成员及批量摘要。已有有效本地 PDF 的条目直接跳过，不创建占位任务；摘要仍记录跳过数量。更换当前批次不会取消旧任务或改变全局 FIFO 队列，第二批新条目和旧失败任务重试继续追加到队尾，网页获取最大并发保持两项。登录、验证码及浏览器下载等待分别显示；这些状态不会仅因暂未得到文件而自动列入“待兜底”，用户仍可明确选择科研通求助。

本地附件预检检查文件存在、可读、为普通文件、PDF 头尾及读取稳定性，支持存储附件和链接文件；它不完整解析正文，也不重新证明论文身份。目录下载与手选导入的身份核验仍独立执行。

## 界面语言、复制与下载诊断

界面支持简体中文、繁體中文及 English。语言选择即时只保存语言，其他尚未保存的积分、检查间隔、自动下载、账号密码输入、已有求助链接、关联目标及任务勾选保持原状。翻译由本地静态词典完成，标题、DOI、文件名和网站消息正文保留来源文字。两个内部浏览器窗口的插件状态文字同步切换，网页内容不由插件翻译。

标题与 DOI 使用可聚焦的复制按钮。标题复制仅去除受支持的行内格式标签，保留真实空格与正文；成功短暂显示复制提示，失败显示明确状态。DOM 套件验证纯文本输出、来源元数据不变、无 HTML 注入、提示到期及失败分支。正式窗口实点另确认 DOI 的复制提示及粘贴内容正确，并观察到标题复制提示；标题的纯文本内容与空格保留由 DOM 回归覆盖，不将该提示单独当作标题剪贴板逐字核验。

“下载检查详情”显示已检查、身份待核对、不匹配的 PDF 数量和最近检查时间，最多显示五个身份未明候选。首次默认折叠；展开状态按任务 ID 在设置页会话内保存，进度刷新、手动检查与筛选切回保留展开，明确折叠也能保留，各任务互不影响。回归验证先展开后立即刷新，无须依赖异步 `toggle` 事件；正式窗口另观察到持续监控刷新约 60 秒后仍展开，预览候选后也保持。候选预览仍只调用预览核对入口，不会暗中确认或导入。

“检查已下载文件”会重新检查任务创建后产生或修改的 PDF，无须重新打开浏览器。自动监控单次最长 30 分钟，只扫描配置目录的直接子文件；诊断及候选属于当前会话，重启后需重新检查。明确匹配的文件才自动添加到原文献；身份不明进入预览与明确确认，冲突文件拒绝导入。网页获取成功或文件落盘本身不代表论文身份核验通过。

## 出版社访问与机构信息

网页线索区分机构入口、可能登录、访问受限、真人验证及自动未找到全文。普通个人账号登录入口不直接认定为机构入口，也不推断当前论文已经获得授权。发现明确指向同一论文标识的出版社页面时可继续该链接，不拼造 PDF 下载地址。

通过浏览器或本地文件取得全文只记录获取经历。用户明确点击“这是通过机构获取”后，才为该论文保存机构访问确认，并提供撤销；同一站点的其他论文只显示历史参考，超过 180 天的经历标记为陈旧。任何历史成功记录均不证明当前论文仍可访问。

日常 Edge 继续使用其自身登录状态。插件不安装 Edge 扩展，不复制其 Cookie，也不接管浏览器调试端口；用户在浏览器中完成网站验证和 PDF 下载，插件通过配置目录核验并入库。插件专用登录窗口的会话保存与日常浏览器会话分别管理。
