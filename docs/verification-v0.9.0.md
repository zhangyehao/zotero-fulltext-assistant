## 真实网络和文件证据

使用公开论文 **Array programming with NumPy**，DOI `10.1038/s41586-020-2649-2`，PMCID `PMC7759461`：

- 通过当前 Europe PMC / PMC Article Datasets 查询取得官方公开 PDF 地址。
- 实际匿名下载 1,218,474 字节、6 页 PDF，无账号、API key 或付费额度请求。
- 原生 Zotero PDFWorker 提取首页；独立 DOI 行紧邻完整、有效且按时间排列的收稿/接受/发表日期，因此可靠识别目标 DOI。
- PDF 自动导入临时条目，附件父条目及文库正确；从存储重新读取后再次核验通过。
- PDF SHA-256：`6728d4ba00fcb73e7872b1cb4b05a7a51482a152da6a9464a15d8f6dcdeb8a3d`。这里只记录公开文件哈希，不分发 PDF。
- 临时条目、附件和测试文件已删除，原任务/提交意图/访问历史及生产额度文件保持原样。

该实测最初暴露 DOI 侧栏被提取到正文之后的问题。修复只接受精确的 publication-history 结构，未放宽短标题或“任意位置出现目标 DOI”的规则；参考文献、错误日期、Correction/归因、第二页、多 DOI 与冲突场景已有回归。

其他来源另有匿名接口观察：OpenAlex 单条元数据请求成功，Semantic Scholar Graph 返回开放 PDF 外链，CORE 匿名请求返回 403。它们分别证明元数据或候选发现能力，**不代表全部来源都完成了真实全文导入**。没有测试真实 OpenAlex 缓存下载扣额，也没有购买或测试 CORE/Semantic Scholar 的付费权限。认证、限额与错误路径另以受控测试覆盖。
