# 0.7.2 更新说明

本版改进“PDF 已下载，但仍在等待”时的身份识别和检查结果。插件只推荐少量有相关证据的候选，将明确不匹配、低相关和识别不足分开显示，避免目录中大量无关 PDF 都成为待核对项。版本面向 Windows / Zotero 10.0.7，仓库和分发继续采用私有、草稿预发布流程。

## 真实 PDF 中的文字与版面差异

本轮排查使用了 *Population genomics of the critically endangered kākāpō*（DOI：`10.1016/j.xgen.2021.100002`）的实际 PDF。文献标题中的 `kākāpō` 与提取文字中的 `kakapo` 存在重音符号差异；普通文本提取还可能把首页页脚 DOI 与邻近页码、图标拼接，导致已经读到标题或 DOI 仍无法可靠确认身份。

标题比较现在兼容拉丁字母重音符号的提取差异。补充的首页版面文字读取保留行、词及其位置，利用文字间距和字号差异分隔 DOI 与邻近的页码、图标，避免把附加标记当作 DOI 后缀。原始 Zotero 标题和 DOI 保持不变。

这项补充使用 Zotero 已有 PDF 提取能力，只将首页文字用于身份判断；接口不可用或补充提取失败时，保留普通文字提取结果。本版没有新增 OCR，也没有直接读取 PDF 超链接目标 URI。一个真实样本的修复不表示所有出版社版式都已适配。

## 标题和 DOI 交叉核对

可靠首页 DOI 与完整标题共同提供证据。有可靠单项证据且没有相反证据时，仍可建立匹配；并非每份 PDF 都必须同时读出两项。

- DOI 一致而可靠本文标题明显不同，或完整标题一致而 DOI 指向另一篇论文，均转为证据冲突，不能自动入库。
- 可靠 DOI 明确指向另一篇论文、也没有完整标题反证时，拒绝导入；稍有相似的标题不能覆盖明确错篇证据。
- 引用区域的 DOI、正文提及的标题、仅第二页命中等不能独立确认本文身份。扫描件或文字提取失败归入识别不足。
- 自动入库仍要求文件格式有效、写入稳定、身份明确匹配且唯一对应等待任务。候选预览始终需要后续明确确认。

标题相似度用于相关性筛选和候选排序，不是论文匹配概率。只有可靠标题明显低相关且没有身份冲突时，才将该文件排除出推荐候选；无法可靠提取不能等同于文件错误。

## 最多 3 个相关候选与分组诊断

**下载检查详情** 现在显示已检查数、相关候选数、已排除数、识别不足数和最近检查时间。

**推荐核对** 按相关程度最多显示 3 个候选，展示文件名、识别标题、识别 DOI、判定依据及可用的标题相似度。相关候选总数可以大于 3，列表只展示最相关的部分。点击 **预览并核对** 仅打开后续核对流程，不自动确认或导入。

**已排除与识别不足** 默认折叠，区分明确不匹配、可靠标题低相关与识别不足，最多展示 5 条诊断记录。这些记录不会作为可操作的推荐候选。文件没有进入推荐区时，仍可用 **选择已下载的PDF** 指定文件，继续执行格式与身份检查，再按结果预览确认。

旧版本只记录了“身份待核对”总数的任务，不会把该数字解释成相关候选数；界面会提示重新检查。外层检查详情和内层诊断区的展开状态在轮询、操作刷新和任务筛选后保留。新增文字覆盖简体中文、繁体中文和英文；文件名、论文标题与 DOI 保持原文。

## 重查计数与已有下载

当前检查按任务和文件路径保留最新分类。同一个文件反复检查不会重复增加已检查数；同一路径的文件内容改变后重新判定，会替换旧分类及对应统计，避免出现同一文件同时留在多个类别里的情况。

**检查已下载文件** 继续检查配置目录中在任务创建后创建或修改的 PDF，不需要重新下载或再次打开浏览器。任务创建前的旧文件可手动选择。已有科研通求助保留原关联；明确匹配的本地文件入库后的来源核验、采纳与对应消息已读规则延续 0.7.1。

诊断计数与普通浏览器候选仍属于当前运行会话，重启后重新检查建立；任务、批次和已获取历史继续持久保存。

## 检查范围与交付边界

本版回归覆盖标题字形差异、首页版面文字、DOI 和标题冲突、提取不足、候选排序、诊断分类、重复检查和覆盖文件后的计数，以及界面展开状态、三语显示与预览确认边界。最终测试结果、安装包校验值、原生检查及正式安装状态以本版交付验收记录为准，本说明不提前声明这些步骤全部完成。

本轮不为测试在真实科研通发布求助、采纳文件或消费积分。真实样本排查与受控测试不能代替网站改版、验证码、机构认证和远端求助全流程验收。之前的测试与安装证据保留在 [0.7.1 验收记录](verification-v0.7.1.md)、[0.7.0 验收记录](verification-v0.7.0.md) 及更早版本文档中，不计作本版重新执行。
