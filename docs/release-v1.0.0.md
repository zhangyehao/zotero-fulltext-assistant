# 1.0.0 更新说明

1.0.0 的发布前验收已完成，以下记录最终候选的功能和验证边界。实际公开安装包以正式 Release 为准；公开旧版升级在发行后独立核验，并把结果追加至 Release 说明，不替换已公开资产。

1.0.0 改进批量获取的等待方式和大列表操作：一个来源返回候选后即开始下载与核对，任务和消息按页显示、在完整记录集合中搜索；同时区分发现渠道与实际 PDF 主机。保留既有任务格式、插件 ID、更新入口、批次/历史与积分授权规则。

## 新增与改进

- 启用的 OpenAlex、PMC / Europe PMC、Semantic Scholar 和带 key 的 CORE 并行发现候选。共享队列逐个处理候选，每次开始下一项前重新排序，优先 PMC 数据集，其次其他 PDF，再处理网页；CORE 托管内容在普通来源候选之后尝试。文件匹配并保存成功后停止不必要的后续请求；匿名 CORE 和自定义模板保留为后续补充。
- 认证限制、限流及临时服务错误进入有上限的退避，并隔离来源、主机和凭据范围，避免整批文献重复请求同一受限端点。其他来源、浏览器下载和已授权的科研通兜底继续保留。
- CORE 普通链接不可用时，可通过已核实的 output 关联使用官方 API 托管 PDF 备用路径。独立开关默认关闭，须有 key 和明确内容授权；本机每日默认 20 次，可设为 1–1000 次。下载前持久化计次，失败、取消和超时也计入。OpenAlex 既有独立预算继续保留。
- 获取记录区分 `discoveryProvider` 和实际 PDF 响应 `pdfHost`。发现服务不再等同于文件托管方；旧数据缺失时回退原来源，不推测主机。科研通已核实积分仍随来源显示。
- 修复 Zotero 原生 302 响应读取缺失可选头时误报失败；修复暂停后迟到进度覆盖和重新获取沿用旧来源。再次手选同一已保存的科研通 PDF 时保留原采纳/已读凭证，避免重复处理。
- 任务与消息默认每页 25 项，可选 50 项；搜索当前筛选下的完整集合。消息可按全部、未读、已读筛选，筛选不会将消息标为已读。
- 隐藏任务/消息页不重复构建列表，未变化的可见行复用；保持输入和详情展开，分页不删除历史、不缩减总数或改变批次范围。
- 设置页更新区改为刷新按钮、状态与当前版本、更新日志展开入口；明确安装、版本说明与原生自动更新选项保留在详情中。
- README 增加繁体中文与英文，三语首页顶部互相切换；补充 API 下载实际发生在本机、来源诊断和社区目录同步说明。

## 更新与使用

实际安装包以 [最新正式 Release](https://github.com/zhangyehao/zotero-fulltext-assistant/releases/latest) 为准；1.0.0 的文件名为 `zotero-fulltext-assistant-1.0.0.xpi`。

已有公开更新入口的 0.8.0/0.9.0 沿用 Zotero 原生更新链路；原始 0.7.x 仍需手动安装一次 0.8.0 或之后的版本。检查更新本身不安装，自动更新时机由 Zotero 决定。第三方市场可晚于 GitHub 显示新版；普通版本一般由采集器发现，不代表每次都等待人工审核。

分页仅改变显示方式。当前批次四个视图、跨批次未完成与倒序完成历史规则保持不变。已有附件、求助关联与设置在隔离原生生命周期中已核对保留；公开更新和跨进程登录保留在发行后单独核验。

## 验收状态

已完成的项目与仍需完成的项目分别记录，不把旧版基线或合成界面结果当作新版真实获取通过：

- 自动化回归：2026-11-09 的最终修复后 `npm test` 中 687 项 JavaScript、偏好设置 DOM 回归和 32 项 Python 测试通过。
- 合成界面：相同 1,000 条任务/200 条消息下，初始元素由 23,481 个变为 913 个；无变化快照不新建列表元素，一条可见消息变化只重建一行。该 LinkeDOM 观察不表示原生 Zotero 或真实下载的提速倍数。
- 真实来源：最终候选以四个 API 联合检查 50 篇，19 篇核对保存、4 篇待核对、27 篇未完成；在隔离空临时条目强制联网，保存后清理，不计正式文库新增。成功即停时最终渠道为 OpenAlex 10 篇、PMC 9 篇，不是各服务独立覆盖率。
- 独立抽样：8 个自定义端点 × 5 篇有 2 次保存、1 次待核对；OpenAlex 最终缓存抽样 5 篇有 2 篇保存，跨修复尝试累计 5 次预留均成功。CORE 最终托管抽样 5 篇仍无保存：302 正确跟随后出现 403 人工验证，本轮预留 3 次、跨修复尝试累计 8 次；本机次数不代表服务 token 成本或余额。
- Windows / Zotero **10.0.8** 候选 XPI 的七组原生验收全部通过，共 250 项，包含菜单/设置生命周期、批次/下载/完成、原生更新、真实 PMC 下载保存、原生分页/搜索和三语交互；合成界面数据不写入文库。
- 计时：最终完整来源检查（50 篇联合、10 篇缓存抽样、40 次自定义端点）为 5 分 15 秒；50 篇端到端中位数 2,218 毫秒，含发现/下载/身份/保存。旧版按单服务独立尝试，模式和预算不同，不据此宣传下载加速倍数。原始文库、DOI、文件路径及逐篇明细不随公开源码发行。
- 最终原生及真实来源候选 SHA-256 为 `7abb23fc6030357cfcb6225a9a616db2a87a585e150770ec32762abd2cea36cc`。正式发行流程独立核对源码、安装包、更新清单和五份资产。
- 旧版至本版公开更新、任务/附件/设置及会话保留：正式更新入口可用后独立验证，并在 Release 说明追加结果；候选检查旧 latest 不算升级通过。

安装范围仍为 **Zotero 10.0.7–10.0.***；本版实际原生验收环境为 Windows / Zotero **10.0.8**，旧版已有 10.0.7 记录，不扩大宣称到其他平台或主版本。本次具体完成范围以以上记录为准。

## 保留的边界

API 返回链接并不代表取得全文。文件需通过有效性和身份核对，冲突拒绝，证据不足仍要求预览确认。CORE 与 Semantic Scholar 不保证覆盖全部文献，key 不授予出版社订阅；API 和自定义下载不继承机构或科研通 Cookie。

CORE API 托管下载消耗服务 tokens allowance，官方没有固定每篇 PDF 单价承诺。本机次数上限不是 token 计量器或账户余额，和 OpenAlex 本机上限一样，不保证不消耗付费额度。插件不自动购买或扩大套餐；正式 API 也受 403、429、额度、许可和文件可用性限制，可能跳转到需要人工验证的网页，配置 key 不保证直供 PDF。

批量普通获取不自动发布付积分求助；人工验证由用户在网站完成。有效会话仍可能过期，插件没有自动解验证码、购买订阅或购买高速权益。新增诊断与退避不保证每个提供方在线，也不保证单篇或全批固定完成时间。

详细配置见 [全文来源与 API](fulltext-sources.md)，本机数据和网络请求见 [隐私说明](../PRIVACY.md)，维护规则见 [UPDATING.md](UPDATING.md)。
