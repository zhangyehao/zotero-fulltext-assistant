原有 39 项知网原生组在此精确候选重跑，另外读取两篇公开 Article 页面。两篇均取得题名、作者和知网标识；其中一篇经明确操作导入元数据，再次导入识别为已有条目，没有重复创建或生成附件。读取页面与参考列表本身没有自动创建文献。

两篇参考列表均为 `unavailable`：读取条数 0、总数未知、未声称完整、真实参考条目导入数 0。**这不表示原文没有参考文献。** 本组没有请求或下载知网 PDF，也没有执行账号登录、机构认证、购买或科研通求助。它与新增输入组分开统计，不能把共四份网页输入写成四次全文成功。

## 合成回归与本地页面重放

代码、控制器、设置 DOM 和原生合成检查覆盖：裸 DOI 与受支持的官方 resolver URL、保留原始官方起点、DOI 字段为空但 URL 有效的选中条目、注册 DOI 冲突拒绝、明确阅读器路径及稳定身份字段、现代学位论文作者与学校分离、PDF / CAJ 按钮区分、标题搜索交接和迟到响应失效。

输入标题时不会调用文章解析、自动选择搜索结果或创建条目。剪贴板和浏览器异常分别处理；输入变更、重置和关闭后的旧预览不能恢复导入按钮或参考文献选择。补全只填空字段，学校写入仅限学位论文。三语控制器和设置页文案与这些状态一致。

另使用本地保留网页重放 DOI 多重解析、阅读器和现代学位论文结构，核对选择器及稳定字段。重放不进行新的网络登录或下载，不作为真实权限证据。含临时参数的合成用例检查 `Referer` 只存在于请求上下文，序列化任务和新导入元数据没有临时密钥；官方 resolver 请求不继承机构、科研通会话或 API key。

中文文件身份核对仍包括冲突拒绝、引用区命中不算本文证据，以及证据不足后的人工确认。合成中文文本或合成 PDF 通过原生 PDFWorker，不等于读取过真实知网机构 PDF。
