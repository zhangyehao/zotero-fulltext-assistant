# 0.9.0 更新说明

0.9.0 把开放全文和 API 放到出版社网页之前，加入设置页内的版本检查与原生更新操作。沿用原插件 ID、任务格式、历史记录、机构/科研通会话和积分授权逻辑，不扩大已验证的 Zotero 版本范围。

## 新增与改进

- 接入 OpenAlex 开放位置与可选缓存 PDF、当前 PMC / Europe PMC 全文路径、CORE 和 Semantic Scholar 候选链接。API 命中后仍需实际下载和身份核对。
- 所有来源集中在设置页配置，支持正式出版版、作者接受稿、预印本偏好；未知版本明确标识。
- OpenAlex、CORE、Semantic Scholar 的 key 使用各自独立的 Zotero 登录管理器记录；空白保留，明确清除才删除，不写入任务 JSON。
- OpenAlex 缓存内容下载另行授权，并以持久化本机次数限制重试消耗。它不代表平台实际账户余额，默认关闭。
- 支持最多 8 个含 `{doi}` 的自定义 HTTPS 模板，分号或换行分隔。默认关闭、无内置镜像列表；匿名请求不携带机构、科研通或 API 凭据，不自动处理真人验证。
- 新来源及出版社自动取得的 PDF 都进入 DOI/标题核对。身份不足的一个候选可跨重启预览确认；冲突文件拒绝导入。
- 任务增加来源检查详情与全文版本；保持已有批次/历史视图、追加队列和跳过已有全文的规则。
- 设置页右上角显示当前版本、检查状态和更新入口，支持查看说明、明确安装及原生自动更新开关。检查不会顺带安装。
- 修复任务读取失败后停用流程可能用空任务覆盖原文件的问题，以及 PDF 提交与暂停/关闭同时发生时丢失来源记录的竞态。
- 简体中文、繁体中文和英文同步新增控件、状态及错误信息。

## 使用与更新

安装 `zotero-fulltext-assistant-0.9.0.xpi`。已使用公开更新地址的 0.8.0 可以通过 Zotero 原生更新取得本版；原始 0.7.x 仍需手动安装一次 0.8.0 或更新版。从 0.9.0 起也可直接在全文助手设置页检查后续版本。

首次打开设置时，已有 OpenAlex key 可自行填入；CORE 与 Semantic Scholar 可先保留空白尝试匿名路径，不必为安装插件先购买服务。源码和 API 文档不能代替提供方的当前账户权限。出版社专用 API 本版未加入。

## 验收与边界

原生目标仍为 **Windows / Zotero 10.0.7**，安装范围 **10.0.7–10.0.***。真实网站、受控模拟和发布后原生升级分别记录于 [0.9.0 验收记录](verification-v0.9.0.md)，不沿用旧版测试数字。

已有浏览器下载、科研通求助与积分授权规则继续保留。有效会话不能保证永久免登录；没有自动解验证码、购买订阅或购买高速下载。CORE / Semantic Scholar 是候选发现渠道，不保证全部文献可用；未知版本和不确定身份仍需用户判断。

配置说明见 [全文来源与 API](fulltext-sources.md)，本地数据与新网络请求见 [隐私说明](../PRIVACY.md)。发行文件为 XPI、源码 ZIP、`updates.json`、`SHA256SUMS` 和 `release-manifest.json` 五份。
