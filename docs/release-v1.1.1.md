# 1.1.1 更新说明

**状态：发布前候选验收完成，待公开发行与公开更新验证。** 本页记录 2026-11-15 验收的精确候选；正式发行状态以 Release 为准。候选自身检查现有公开更新源，不等于旧版已经升级至本版。

1.1.1 修复知网 DOI 入口、阅读器链接和现代学位论文页面的兼容问题，并把 DOI、官方链接和完整标题放入同一个输入框。它保留“先预览、明确导入”和原有全文身份核对流程。

## 修复与改进

- **DOI 和官方多重解析。** 支持裸 DOI、`DOI:` 前缀、`doi.org` 以及已支持的知网和中文 DOI 官方解析入口。多重解析页须提供与目标 DOI 一致的注册信息及明确文章链接；保留用户输入的有效官方解析起点，避免丢掉直链后强制改走另一服务。已有条目只有官方解析 URL、DOI 字段为空时，也能进入验证和补全。
- **阅读器链接。** 支持明确的 `ix.cnki.net` 和 `x.cnki.net` 阅读路径及可核对的数据库、文件标识。只返回空阅读壳时保持“元数据不可用”，需要用户提供该文献的详情页链接；不会把产品名称当作论文标题。
- **现代学位论文。** 兼容新的隐藏字段和作者区域，保留完整文件标识；授予单位单独显示并保存到学位论文的学校字段，不混入作者。对共用历史样式的 PDF / CAJ 按钮，结合实际文字和目标格式判断；明确 CAJ 仍不当作 PDF。
- **统一输入和标题搜索。** 在“Zotero 设置 → 全文助手 → 设置 → 知网”输入 DOI 或官方链接时显示“解析文献”；输入完整标题时显示“搜索标题”。插件尝试复制标题并打开官方搜索入口，由用户搜索、选择正确文章并填回详情链接。不会自动选择第一条结果或把搜索交接记为解析成功。
- **预览与导入的一致性。** 输入变化、标题搜索、会话重置及关闭后，旧异步结果不能恢复过时预览或参考文献选择。现有条目只补空字段；三种界面语言覆盖新按钮、状态与授予单位。
- **下载权限核验。** 页面 PDF 入口进入知网权限中间页时，在自动请求前停止并显示 `access_check_required`，交给浏览器继续核验。这个状态不表示必须付费，也不表示已经取得 PDF。
- **临时来源地址。** 下载所需的临时 `Referer` 只用于运行时请求，任务、来源诊断和新导入题录保留稳定标识与链接；官方 DOI 解析请求不带机构、科研通 Cookie 或 API key。

详细输入范围、操作步骤与访问限制见 [知网说明](cnki.md)。本版仍使用网页明确提供的资料和下载入口，不内置未获授权的 OpenX 应用凭据，也不自动购买文献。

## 更新与兼容

安装包文件名为 `zotero-fulltext-assistant-1.1.1.xpi`，兼容声明保持 **Zotero 10.0.7–10.0.***；本版实际原生测试环境为 **Windows / Zotero 10.0.8**。插件 ID、公开更新地址和 schema 1 任务存储格式不变。

已有本地全文跳过、批次追加、跨批次未完成、完成历史倒序、下载目录检查、科研通积分授权与采纳凭证规则保持兼容。知网入口变化不要求重建文库，也不自动发布付积分求助。原始 0.7.x 仍需手动安装一次 0.8.0 或之后版本；已有公开更新入口的版本沿用 Zotero 原生更新链路。

## 仍未验证的访问条件

**真实知网 PDF 下载、完整参考文献列表，以及机构登录跨进程恢复仍未验证。** 页面题录可读、发现 PDF 按钮、会话保存授权存在和合成回归通过，都不能替代这些结果。网站权限核验页也不能用于推断已经购买或必须购买。

知网与其他出版社使用 Zotero 网站会话；插件不读取日常 Edge / Chrome Cookie。默认浏览器已有权限时，可沿用 [下载目录检查与人工核对](browser-downloads.md)。公开 Release、五份资产匿名读取、旧版公开升级和插件目录采集状态，须在正式发布后分别核验。
