# 知网文献与全文

本文说明 **1.1.0** 的知网功能，更新于 **2026-11-15**。本页区分已经实现的流程、公开网页检查结果和仍未验证的机构访问条件；实际安装包以 [正式 Release](https://github.com/zhangyehao/zotero-fulltext-assistant/releases/latest) 为准。

## 适用范围

知网功能把中文文献的网页资料和 PDF 接入原有任务队列。条目已有 DOI 时，可以结合 DOI 与页面资料核对；没有 DOI 时，可以使用已知知网文章网址及其中的数据库、文件标识。找到题录、出现 PDF 链接、网站允许下载以及文件通过身份核对，是四个不同步骤。

当前解析范围包括官方站点的 `KCMS/detail/detail.aspx`、`kcms2/article/abstract` 和 `Article/<数据库>-<文件>.htm` 文章页；能否取得完整资料取决于网址参数和页面实际内容。搜索结果页、登录页及其他产品入口不能直接当作文章页导入。知网期刊门户等不同结构的页面未因此自动获得支持。

| 资料情况 | 处理方式 |
| --- | --- |
| 已有 Zotero 条目，带 DOI 或明确知网文章网址 | 查询页面资料；在可核对身份的条件下补充空字段，并通过原有批量任务获取 PDF。 |
| 只有知网文章网址，尚未建立条目 | 先预览题名、作者等资料，再明确选择导入；导入前检查重复条目。 |
| 中文题名明确，但没有 DOI 或文章网址 | 打开知网官方搜索入口，由你确认正确文章；不会默认把第一条检索结果认作目标。 |
| 页面提供 PDF，当前 Zotero 会话有访问权限 | 尝试页面实际提供的下载链接；文件格式和论文身份通过核对后才保存附件。 |
| 需要机构登录、验证码或网站拒绝访问 | 保留网页登录和默认浏览器下载入口；完成网站要求后重试或检查本地文件。 |
| 只提供 CAJ 或其他非 PDF 文件 | 显示格式限制并保留网页处理入口；不改扩展名冒充 PDF，也不把题录记为全文。 |

本版不承诺自动购买文献、通用免费全文或所有知网产品都能下载。已有本地全文的跳过、追加批次、暂停、未完成和历史规则沿用原队列；科研通求助仍须按原授权规则明确启动。

## 在设置中使用

在 **Zotero 设置 → 全文助手 → 设置 → 知网** 中管理 **启用知网来源**、**网页登录**、**重置知网会话** 和 **验证访问**。来源默认开启，开关即时保存。元数据及网址操作在同一设置页提供，不需要安装浏览器扩展或 Jasminum。

1. 确认已启用知网功能。已有条目可使用 **补全选中条目元数据**；新网址先点 **解析链接** 预览资料，再明确选择 **导入为新条目**。已有条目只补空字段，新条目导入会检查重复。
2. 需要机构权限时，使用知网网页登录入口，在 Zotero 窗口中完成站点或机构认证。按窗口提示完成并记住本次会话，再检查当前页面是否已经提供可下载 PDF。
3. 回到文库，通过 **全文助手 → 批量获取全文** 处理选中的条目。下载结果进入原有任务和历史；元数据预览本身不会产生“已获取”记录。
4. 需要重新登录时，可从知网设置清除该范围会话后再登录。清除不删除已导入文献、PDF、任务历史，也不等于清除科研通账号。

知网与其他出版社共用 Zotero 的网站会话机制，知网设置提供该范围的操作入口。“已允许保存知网会话”表示已授权保存这个网站范围，不证明已经产生 Cookie 备份、登录成功或取得下载权。网站仍可使会话到期或撤销权限。插件不读取 Edge / Chrome Cookie，不接管你平常浏览器中的登录。默认浏览器能下载而 Zotero 不能时，可使用现有的 [下载目录检查流程](browser-downloads.md)。

## 元数据与 PDF 如何对应

页面可能给出 DOI，也可能主要依赖 `dbcode`、`dbname`、`filename`。这些字段不是 DOI 的替代写法：`dbcode` 表示数据库类别，`dbname` 标明具体库，`filename` 是文献文件标识。插件保留可核对的来源信息，不能把某个数据库类别写死为全部知网文献。`filename` 可能包含小数点等字符，不能仅按字母和数字截取。已知旧期刊类别 `CJFQ` 与 `CJFD` 会规范为同一身份，其他数据库或文件名冲突仍需拒绝。

元数据补全只填入空字段，不覆盖你已有的题名、作者或其他资料。页面身份与现有条目冲突时，停止自动写入；没有明确文章链接的题名搜索，也需要先确认目标。新条目预览和去重不会跳过原有 PDF 身份核验。

中文 PDF 可能没有 DOI，文字提取也可能出现空格、换行或断字。知网文件仍须通过实际论文的题名及其他可用证据核对；可靠冲突应拒绝自动导入，证据不足保留人工预览。参考文献中出现目标题名或 DOI 不足以认定文件正确。版本证据不足时沿用“版本未核实”，不因为来源是知网就默认认定为正式出版版。

## 提取和导入参考文献

解析一篇文章后，在 **文献预览** 下点击 **提取参考文献**。插件读取该页实际可见的直接参考文献；页面明确声明可读取的同站引用列表地址时，本次明确操作最多再读取一个候选地址。不会猜测接口参数、生成令牌、绕过登录，或把引证文献、二级参考文献和相似文献混入列表。

列表按网页提供的数据库分组保留信息，最多整理 500 条。题名、年份、DOI 和文章网址只有具备明确字段或网页结构证据才提取；不能可靠拆分的引文保留原文，不随意将整段文字当标题。未拆分的作者保留原样，避免把多个人名拼成一个作者。

默认没有勾选任何条目。核对后选择 **导入所选参考文献**，每次 1–50 条；导入会查重，并在当前可编辑文库/分类中创建独立文献条目。只有原文而缺少可靠题名的行不能直接导入。导入的是文献资料，不表示已经取得该文献的 PDF；之后可选中这些条目，使用正常批量获取全文。

**当前版本不保证得到完整参考文献列表。** 官网可能只提供“前 N 条”，或返回需要登录、权限不足、人工验证、检索降级等结果。已读取的公开部分可保留展示；总数未知时保持未知，不把读取条数当总数。没有读到列表也不代表原文没有参考文献。需要更多内容时，从原文章网页完成登录或验证，查看网站实际列表后再重试；仅在网站提供导出且你有权限时使用其导出功能，不把不完整结果标记成完整。

## 真实网站检查范围

2026-11-15 的只读检查使用以下两个官方公开页面，均取得页面并解析出元数据及页面声明的参考列表入口：

| 样本 | 公开检查结果 |
| --- | --- |
| [非侵入式纳米纤维基比色传感器的研究进展](https://www.cnki.com.cn/Article/CJFDTOTAL-DHDZ202305001.htm) | 可解析题名等元数据；按页面原样声明的列表地址请求后，网站返回“检索降级”，没有提供参考文献。 |
| [基于部分酸水解-亲水作用色谱-质谱的黄芪多糖结构表征](https://www.cnki.com.cn/Article/CJFDTOTAL-SPZZ201412003.htm) | 可解析题名和作者等元数据；页面有授权/购买提示，并声明参考列表入口。未把声明入口本身算作参考列表读取成功。 |

其中的“检索降级”响应为成功 HTTP 响应内的不可用状态，插件保留总数未知，不显示成零引用。这些检查**不构成完整参考列表或 PDF 下载成功的证据**。目前尚未验证用户机构授权的知网 PDF 下载，也未将公开页面检查当作知网登录跨进程恢复的实测结果。实际可见列表、受限列表、导入结果和原生界面的检查需按各次候选记录；机构权限、验证码和网站服务状态仍会影响结果。

## 官方接口与网页访问的区别

知网研学开放平台 **有官方 API**。截至 2026-11-15 核对的官方文档，使用者需建立开发者应用、申请所需接口并等待审核，再按接口要求使用应用信息与 JWT。普通知网账号、机构 IP 或浏览器 Cookie 不等于已获批的开发者接口权限。[官方概述](https://openx.cnki.net/docs/guide/overview.html) · [快速开始](https://openx.cnki.net/docs/guide/quick_started_api.html)

[文献接口文档](https://openx.cnki.net/docs/guide/file_api.html) 列出以下题录能力，路由前缀为 `https://gateway.cnki.net/openx/`：

| 官方文档列出的接口 | 输入与用途 |
| --- | --- |
| `GET /psmc/file/doi/tilu/infos` | 以 `doi` 查询知网库题录。 |
| `GET /psmc/file/references/tilu/infos` | 以 `documentId` 查询题录和参考文献资料。 |

这些接口说明了元数据能力，不代表取得相应论文 PDF 的授权。官方接口还区分应用权限、会员权限、限流等返回结果；不能将错误统一解释为没有全文。认证模式和错误定义见 [JWT 文档](https://openx.cnki.net/docs/guide/jwt_api.html) 与 [接口规范](https://openx.cnki.net/docs/guide/develop_standard_api.html)。

1.1.0 的首个实现范围采用论文网页提供的资料、引用列表与下载入口，**不内置未获授权的 OpenX 应用凭据，不通过猜测接口地址取得文件**。网页明确声明的引用列表请求是该页面的读取流程，不等于开放平台通用 API 授权。如以后接入正式 API，应另外确认应用授权、用户认证、额度与凭据存储；不能直接把网站登录转换成通用 API 服务。

## 验收时分别记录

1. 已有条目和新网址的预览、补空字段、去重、非 DOI 标识保存；冲突及仅有题名时不误关联。
2. 开关关闭、有效页面、需要登录、验证码、仅 CAJ、失效链接、有效 PDF 与身份不足文件。
3. Zotero 内登录、跨进程重启恢复、知网范围清除，以及 Edge 独立会话边界。
4. 批量已有全文跳过、追加队列、暂停与重启、历史保留；原有科研通来源和采纳凭证不受影响。
5. 参考文献分组、部分/未知总数、原文与明确字段、门禁、检索降级、默认不勾选、每次至多 50 条导入及重复项处理；晚到响应不得把上一文章的引用写入新预览。
6. 最终 XPI、版本、提交、哈希及真实机构权限条件。模拟接口和公开网页成功不能代替订阅全文、完整参考文献或跨重启登录验收。
