## 本版行为与本地检查范围

设置页采用 **任务 / 下载设置 / 科研通账号 / 消息** 横向标签栏。默认任务页显示未完成任务；没有可求助项时隐藏批量求助栏。左右方向键、Home、End 与鼠标可切换标签，切换保留未保存的积分、间隔、自动下载、账号输入、任务筛选和勾选。新批次结束后切回任务页展示一次摘要，同一摘要的轮询更新不会打断当前页面。摘要使用纯文本呈现，只保留在当前会话；任务、历史和账号存储方式不因标签切换改变。

任务标题、关联文献选项和待核对文献标题仅移除 `i/b/em/strong/sub/sup/span` 行内格式标签，以 `textContent` 显示纯文字，不解析来源 HTML。DOM 回归验证大小写标签、带属性标签、数学比较及未识别尖括号、原元数据不变，并保留原 XSS 测试；该修正不进入 DOI 或 PDF 身份核验流程。

右键 **全文助手** 子菜单集中批量获取、显式科研通兜底和任务设置入口。批量选择子附件时取得其父文献，同一父文献去重；独立附件和笔记忽略。创建或修改任务前，遍历该文献所有本地附件，检查文件存在、可读、为普通文件，头部为 PDF 标记、尾部含结束标记，读取前后大小与修改时间一致。存储附件和链接文件均可计入；链接 URL、丢失文件、HTML 伪装及不完整文件不使条目跳过，前一个无效附件也不遮蔽后续有效附件。此处只检查头尾，**不完整解析 PDF，也不重新验证论文 DOI**。

存在有效本地 PDF 时跳过，不新建任务或删除原历史。原任务正在处理、等待浏览器下载、待人工核对、已有远端求助或处于受保护提交状态时保留原记录。可重试且无关联的失败/暂停任务可以复用并重新排队，普通批量会撤销旧的未提交求助许可；显式兜底可处理符合条件的浏览器等待与人工核对任务。已获取任务的 PDF 丢失时复用原任务修复，既有远端求助及其原预算保留。每批显示加入、已有 PDF 跳过、保留、重复选择、不支持及检查失败数量，单项错误不阻止后续条目。

目录下载、手选 PDF 核对、科研通登录、消息、积分即时显示、已有求助关联等功能延续上一版；本轮实际 XPI 重跑范围如下，不扩大为所有真实网站重新验收。

## 连续批次与科研通收尾

第一批未结束时继续提交批次，新任务和旧失败任务重试都追加到当前队尾。已在处理或排队的重复条目不重启，原任务 ID 和已发布求助预算保留。列表按照实际排队顺序显示队位，切换筛选不改变队位；正在获取、排队、等待应助与等待浏览器下载分别统计。当前网页获取并发上限保持两项。

科研通下载现在也核验 PDF 首页可信 DOI 或完整标题。只有具体文件的字节经核验且成功保存为原条目的附件，才持久保存求助、文件、账号、附件、SHA-256 和核验依据，然后采纳该文件、结算原悬赏，并逐条标记其上传通知已读。采纳前重新核对本地附件内容和所属文献，并在网站核实登录账号、求助所有者、DOI、文件状态和采纳按钮；不以“下载返回成功”代替论文正确。

采纳与消息状态独立持久保存，重试不重新下载附件。采纳 POST 之前保存待核对标记；超时或重启后若结果不明确，只读取网站核对，不盲目重复提交。已采纳后消息失败只继续已读步骤。新出现的同文件上传通知会再次进入已读处理；其他消息不改。未收尾记录仍在“未完成”中提示，同时可从“已获取”打开 PDF。

无法自动判定的应助 PDF 暂存为待核对文件，跨应用实例重建后恢复预览与明确确认入口；改变文件字节或文献身份会阻止旧确认。旧版已获取记录不凭空创建采纳凭据，提供“核验并补采纳”：重新取得的候选必须与已存附件字节完全相同，且论文身份明确匹配，才能补采纳，不重复入库。

采纳与单消息已读协议依据保存的官方页面和脚本核对；本轮没有执行真实采纳或消息已读 POST，也没有为测试结算悬赏。Node 适配器测试以受控 HTTP 响应验证实际协议分支；原生收尾测试替换科研通适配器，验证真实 Zotero PDF、入库和持久化流程。两层测试覆盖正确顺序、身份不匹配、持久化失败、超时核对、账号切换、附件改变、未知 PDF、旧历史及应用实例重新初始化后的恢复。此范围不能替代真实网站的最终成功证明。生产流程中的采纳会结算该求助原有的悬赏，并非仅作本地状态标记。

## 证据边界

- 本地附件头尾检查只能识别基本文件结构，不能保证 PDF 每页均可解析或正文属于所列文献；目录下载和手选导入的论文身份核验仍按原流程执行。
- 实际 XPI 验收需注明使用真实 Zotero 数据库、文件 API 和附件导入的部分，以及网络、系统浏览器、文件选择器等被替换的测试边界。合成 PDF 或离线夹具不证明真实网站验证码、机构登录或浏览器下载完成。
- 生命周期停用/启用不等于完全退出并重启 Zotero；也不能推定机构服务端在重启后仍认可会话。
- 新求助真实发布、等待新的应助并下载的完整链路未计入本轮验收。界面及批量预检测试不发布真实科研通求助或消费积分。
- 科研通采纳及单消息已读未在本轮执行真实网站 POST；原生收尾报告中的成功状态来自模拟适配器，不能表述为真实网站已采纳、已结算或已读成功。
- 旧版 PLOS、Nature、CSTCloud 和已有应助文件的成功记录保留在历史文档，不写作本版重新实测。远端同步、标签、草稿发布与社区收录是独立分发流程。
