## 候选与诊断行为

- 推荐区最多显示 3 个明确存在相关线索的候选，按相关程度排序，并展示识别标题、DOI、判定依据与可用的标题相似度。相似度不是匹配概率。
- 明确不匹配、可靠标题低相关和识别不足分组显示，诊断默认折叠，最多展示 5 条记录。没有可靠提取结果时不宣称文件错误；仍可手动选择 PDF 预览核对。
- 同一任务当前检查按文件路径保留最新结果，重复检查不重复累加；同一路径文件改变后替换原分类统计。旧版没有分类字段的记录提示重新检查。
- DOI 与可靠完整标题相互矛盾时不自动入库。有可靠单项证据且没有冲突时仍可匹配，不要求每份 PDF 同时读出两项。
- 候选预览不自动确认或入库；确认前继续核对文件内容与文献身份。两层诊断展开状态在轮询、操作刷新和切换筛选后保留。

## 边界与分发

本版没有新增 OCR，也没有直接读取 PDF 超链接目标 URI。使用的是 Zotero 已有文字提取与首页版面文字能力；几何文字不可用时保留普通文字结果。扫描件、保护文件、复杂版式仍可能需要人工核对。当前真实样本的修复不证明所有出版社 PDF 均可识别。

本轮不会为了边界测试在科研通发布新求助、采纳文件或新增悬赏。已有科研通流程继续要求论文身份、网站具体文件和完整内容核验；本记录不把隔离模拟中的采纳或已读结果冒充真实网站操作。真人验证与机构登录仍由用户完成，插件不会因此取得日常浏览器 Cookie 或绕过网站验证。

交付清单为 XPI 安装包、完整开发源码 ZIP、HTML 使用说明与 HTML 验收记录四项。交付核验要求源码包中的生产文件与实测 XPI 一致，并核对每项资产的名称、大小与 SHA-256；该清单及标准不单独构成封装完成证明。资产不得包含用户任务、论文 PDF、登录数据库、Cookie 或真实目录复核原始数据。两份 HTML 沿用原有样式，本轮完成结构与静态内容检查，不宣称浏览器渲染验收。

仓库采用私有分发政策，版本发布保持草稿与预发布状态。发布流程要求精确对应的提交与标签、GitHub CI 通过，并核实四项交付资产的大小和 SHA-256；仓库中的本地验收记录本身不证明这些远端步骤已经完成。实际远端结果由 GitHub 对应提交的 CI 状态及随附 HTML 验收记录提供，不等同于公共发布或插件市场收录。
