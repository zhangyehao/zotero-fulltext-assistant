# 0.8.0 更新说明

0.8.0 将全文助手整理为首次公开发行版本。保留原插件 ID 和既有任务数据格式，新增可匿名访问的 GitHub Release 更新源、可复现的发行资产、隐私与支持说明，并将长篇开发记录移入历史文档。

## 面向用户

- 一个 Zotero 插件完成批量网页获取、日常浏览器下载后的本地核对，以及明确授权后的科研通兜底。
- 设置页保持“任务 / 设置 / 科研通设置 / 消息”，支持简体中文、繁體中文、English。
- 已有可用本地 PDF 的条目在批量预检中直接跳过；新任务追加到队尾。当前批次分类与跨批次未完成、完成历史分别显示。
- 浏览器下载保留相关候选与诊断；手选已有求助的 PDF 需要预览确认，核实网站具体文件后才恢复科研通来源和继续采纳。
- 默认 10 积分可调，自动接受网站最低悬赏默认关闭；来源显示已核实的实际金额，支出统计明确限定为本机已采纳记录。
- README 改为安装与使用指南；新增隐私、支持和问题模板，截图使用不含私人资料的空白演示文库。

以上功能包含 0.7.x 已完成并延续的行为；本次发布整理不意味着每项网站流程都首次实现或全部重新实站验证。

## 安装与更新

从本仓库正式 Release 下载 `zotero-fulltext-assistant-0.8.0.xpi`，在 Zotero 插件管理器选择“从文件安装插件”。0.7.x 用户需要手动安装一次本版，以取得新的公开更新地址；安装使用同一个插件 ID，升级无需建立新的任务库。

更新地址为：

```text
https://github.com/zhangyehao/zotero-fulltext-assistant/releases/latest/download/updates.json
```

更新清单指向版本固定的 XPI，包含 SHA-256 与 Zotero 兼容范围。是否已实际发现并安装升级，应以 Zotero 升级验收结果为准；仅生成更新清单不构成升级成功的证明。

## 支持与验证范围

原生验证环境为 **Windows / Zotero 10.0.7**，安装清单范围为 **`10.0.7–10.0.*`**。未扩大到 macOS、Linux、Zotero 7/8/9 或 10.1+。旧版测试数字、Nature/PLOS 下载和机构会话验证继续保留在对应历史报告中，不计作本版重新执行。

本版实际 XPI 的原生检查通过 **180/180**：插件与生命周期 66 项、浏览器目录下载与 PDF 核对 31 项、批量与队列 48 项、采纳及消息收尾 35 项。这些检查包括受控数据和模拟网络边界，不等同于真实网站新求助、应助、付费结算全链路验证。正式文库通过插件管理器从 0.7.2 手动升级到 0.8.0，既有任务与配置完整保留，8 项升级保存检查通过。详见 [0.8.0 验收记录](verification-v0.8.0.md)。具体构建和自动化结果见对应提交的 CI；公开更新发现与升级是发布后单独核实的步骤。

插件不绕过机构订阅或验证码；签到仍需本人在官网完成。默认浏览器网页仍由用户操作。科研通求助发布需要明确授权，下载及采纳应遵循网站规则与文件权限。GitHub Release 发布和第三方插件目录收录是独立结果。
